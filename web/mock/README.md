# WebUI Mock

```sh
npm --prefix web run dev:mock -- --port 5173 --strictPort
```

登录 Token 为 `mock`。Mock 在 Vite 内提供 HTTP API 和模拟 WebSocket 终端，无需 Go 服务端或客户端。普通 `npm --prefix web run dev` 继续使用真实后端代理；生产构建不启用 Mock 插件或控制面板。

默认提供27个节点：16在线、6离线、2待加入、1待审核、1拒绝加入、1密钥过期，涵盖 OpenWrt、Padavan、macOS、Linux amd64/arm64 和 Windows。样本包含中文/长名称、陈旧上报、高CPU/低内存、采集失败与缺失指标。每个已登记节点有28条历史记录，支持分页；`windows-build-queued` 和 `windows-desktop-busy` 用于观察排队、执行中及节点忙的样式。

左下角 **MOCK** 面板可以重置完整数据、全部在线、全部离线、切换空列表，或模拟待加入节点上线。支持创建、重命名、重新生成加入串、审核允许/拒绝、删除、登录和退出；拒绝、过期和删除释放名称。节点ID为十进制自增序号；右侧独立展示节点信息、已采集的设备信息和历史，无采集时隐藏设备卡片。数据保存在开发服务内存中，刷新浏览器保留；重启 Vite 或重置会恢复样本。加入串仅供界面预览，不可用于真实设备登记。

Web 仅保留交互终端和执行历史。Mock 命令 API 支持任意文本的模拟成功结果，以下命令用于展示不同状态：

| 命令            | 场景                       |
| --------------- | -------------------------- |
| `mock:help`     | 可用场景说明               |
| `mock:success`  | 成功                       |
| `mock:error`    | 标准错误、失败、退出码7    |
| `mock:stderr`   | 成功并附带警告             |
| `mock:timeout`  | 超时                       |
| `mock:unknown`  | 失联、结果未知             |
| `mock:truncate` | 多行日志与截断提示         |
| `mock:empty`    | 空输出                     |
| `mock:unicode`  | 中文、Unicode、JSON文本    |
| `mock:slow`     | 12秒任务，观察排队和执行中 |

模拟终端支持 `help`、`cd`、`pwd`、`ls`/`dir`、`echo`、`export`/`set`、`env`、`whoami`、`hostname`、`uname`/`ver`、`date`、`cat`、`df`、`free`、`stty size`、`top`、`ping`、`sleep`、`clear`/`cls`、`exit`，以及退格、历史上下键和 Ctrl+C。切换标签保留独立目录和环境变量；重载重建会话，关闭释放占用，不生成历史。

所有命令和终端均为文本模拟，不调用系统 shell。终端使用现有 xterm.js 与 [ws](https://github.com/websockets/ws) 的 WebSocket server，真实前端组件保持原样。

文件工作区提供每节点独立的内存文件树：Unix 初始 `/root`、Windows 初始 `C:\Users\Administrator`，含隐藏文件、嵌套目录、245个文件的 `many` 目录、空文件、混合换行文本、2MiB以上只读和10MiB以上仅下载样本，以及PNG/SVG/WAV/WebM/PDF。界面使用扁平列表，`..` 返回上级；支持分页、名称过滤，以及名称、时间、类型、大小、权限、用户/组排序。创建、剪切、复制、拖动、重命名、删除、文本保存与上传均只修改开发服务内存；下载返回内存文件内容，刷新页面保留已提交文件；重置场景或重启服务清空。

文件连接预览样本直接位于各节点初始目录：`文件软连接.txt` 指向 `连接示例.txt`，`文件硬连接.txt` 与该文件共享内容，`文件夹软连接` 指向 `config`，`失效连接.txt` 用于预览断链提示。Windows 节点另有 `文件快捷方式.lnk`、`文件夹快捷方式.lnk`。普通目录使用原 `assets/folder.svg` 实心图标，目录连接使用相同轮廓加深色连接箭头的 `assets/folder-symlink.svg`，文件连接使用 file-symlink；两类目录图标均保留原 SVG 的 `#ffcc66` 黄色，目录连接与目录统一优先排序、计数后分页。双击文件连接预览真实内容，双击目录连接进入目标目录。连接仍支持右键编辑，改变目标后刷新图标。

全局文件会话绑定登录，上传支持确认偏移、暂停/继续与覆盖冲突；全局进度框只展示上传，下载直接交给浏览器。关闭节点标签或隐藏进度框，上传继续；刷新页面不恢复队列。关闭文件会话、注销或删除节点中断对应任务。文件编辑窗口支持多标签、固定、点击外部隐藏以及顶部/底部拖动；未保存文件显示红色标题和全局角标。Mock文本保存仅支持UTF-8；GBK编码、权限、磁盘满、真实网络背压与设备清理需使用真实Agent验证。媒体样本由本地生成的图形、音调与视频组成，PDF含两个不同页面及用于检查不执行脚本的OpenAction；不引入外部媒体或CDN。

每节点最多8个独立模拟Shell，支持cd/pwd命令，各Shell目录独立；新分屏从默认目录开始，不注入提示符或上报路径变化。Web终端不生成执行历史；历史仅由模拟命令API产生。映射API支持按节点过滤、TCP/UDP、本机/LAN目标与添加/删除；监听地址以 `:6660` 结尾模拟端口占用，目标端口 `6661` 模拟连接失败，节点离线单独显示。所有映射均为界面模拟，不创建真实监听或目标连接。

上传名为 `mock-no-space.bin` 的文件会返回模拟507，以检查失败状态和错误文案；覆盖冲突保持暂停并要求点击覆盖。
